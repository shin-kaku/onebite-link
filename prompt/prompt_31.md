# 사이드바 링크 검색 기능

- 왼쪽 사이드바의 `전체` 버튼 아래에 돋보기 아이콘이 포함된 검색창을 추가했다.
- 검색어를 입력하면 현재 사용자가 열람할 수 있는 링크를 즉시 필터링한다.
- 링크 제목, 설명, URL, 폴더 이름을 검색 대상으로 사용한다.
- 폴더 화면에서 검색을 시작하면 자동으로 전체 링크 화면으로 이동해 전체 컬렉션에서 검색한다.
- 검색어의 앞뒤 공백과 한글·영문 대소문자 차이를 무시한다.
- 검색 결과가 없으면 다른 검색어를 입력하도록 안내하는 빈 결과 화면을 표시한다.
- 검색창은 기존 사이드바의 색상, 테두리, 포커스 스타일을 유지하도록 구성했다.
