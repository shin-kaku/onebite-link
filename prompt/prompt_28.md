# 마스터 공용 데이터 기능 적용

- 마스터 계정 UUID를 카카오톡 로그인 곽신 계정으로 설정했다.
- 로그인 사용자는 자신의 폴더·링크와 마스터 계정의 폴더·링크를 함께 조회한다.
- 마스터 소유 데이터는 모든 로그인 사용자에게 기본 데이터로 표시된다.
- 일반 사용자는 마스터 데이터를 수정하거나 삭제할 수 없으며, 화면에서도 수정·삭제 버튼이 표시되지 않는다.
- 마스터 계정은 자신이 만든 기본 데이터를 계속 수정·삭제할 수 있다.
- 일반 사용자는 마스터 기본 폴더에 자신의 링크를 추가하거나 이동할 수 있다.
- Supabase RLS 정책을 작업별 SELECT·INSERT·UPDATE·DELETE 정책으로 분리해 위 권한을 데이터베이스에서도 강제한다.
- 계정이 변경되면 기존 데이터를 비우고 새 사용자의 데이터와 마스터 기본 데이터를 다시 불러온다.
