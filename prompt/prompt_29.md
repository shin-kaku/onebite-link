# 마스터 데이터 공개·비공개 기능

- `folders`, `links` 테이블에 `is_public boolean not null default false` 컬럼을 추가했다.
- 기존 마스터 소유 폴더와 링크는 이전처럼 계속 노출되도록 공개 상태로 설정했다.
- 새로 생성하는 폴더와 링크는 기본적으로 비공개 상태로 저장된다.
- 마스터 계정 화면에 폴더·링크별 공개/비공개 전환 버튼을 추가했다.
- 링크를 공개하려면 먼저 해당 폴더가 공개 상태여야 한다.
- 폴더를 비공개로 전환하면 그 안의 공개 링크도 다른 사용자에게 표시되지 않는다.
- 일반 사용자는 공개된 마스터 데이터만 조회할 수 있고 수정·삭제·공개 상태 변경은 할 수 없다.
- Supabase RLS 정책을 공개 상태까지 검사하도록 변경하고, 일반 사용자가 자신의 데이터를 공개 데이터로 만들 수 없도록 제한했다.
