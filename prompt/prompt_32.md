# 사이드바 사용자 정보 표시

- 로그인한 사용자의 이름과 이메일을 왼쪽 사이드바 최상단에 표시하도록 추가했다.
- 이름은 `안녕하세요. Display name님!` 형식으로 보여준다.
- 사용자 메타데이터의 `display_name`, `full_name`, `name`, `nickname`, `user_name` 순서로 표시 이름을 찾는다.
- 표시 이름이 없는 이메일 가입자는 이메일의 `@` 앞부분을 이름으로 사용한다.
- 사용자 정보는 Supabase Auth가 반환한 현재 사용자 객체에서 가져오며 권한 판별에는 사용하지 않는다.
- 로그인 상태가 변경되면 사용자 이름과 이메일도 함께 갱신된다.
- `사용자 정보`, `전체 버튼 + 링크 검색`, `폴더 목록` 세 영역 사이에 구분선을 추가했다.
- 기존 사이드바의 Notion 스타일 색상, 글꼴, 간격을 유지했다.
