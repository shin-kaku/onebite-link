# 사용자 역할 단계 추가

- `public.app_role`에 `master`, `graduate`, `student` 역할을 정의했다.
- `public.user_roles` 테이블에서 Supabase Auth 사용자별 역할을 관리하도록 구성했다.
- 기존 마스터 계정은 `master`, 나머지 기존 계정은 `student`로 등록했다.
- 신규 가입자는 데이터베이스 트리거를 통해 자동으로 `student` 역할을 받는다.
- `master`: 마스터 폴더와 링크의 공개·비공개 상태를 결정하고 수정·삭제할 수 있다.
- `graduate`: 공개 여부와 관계없이 마스터의 모든 폴더와 링크를 열람할 수 있지만 수정·삭제할 수 없다.
- `student`: 공개된 마스터 폴더와 링크만 열람할 수 있으며 마스터 데이터를 수정·삭제할 수 없다.
- 모든 사용자는 자신의 개인 폴더와 링크를 기존처럼 관리할 수 있다.
- 역할 판별은 보호된 데이터베이스 함수와 RLS 정책에서 수행되며 변경 사항은 즉시 적용된다.
- 사용자 역할은 Supabase 대시보드의 `Table Editor → user_roles`에서 해당 사용자의 `role` 값을 변경하여 관리한다.
