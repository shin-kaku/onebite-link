# 프로젝트 및 저장소 이름 변경

- 프로젝트 패키지 이름을 `3.onebite-link`에서 `typography-bookmarks`로 변경했다.
- `package.json`과 `package-lock.json`의 프로젝트 이름을 동일하게 맞췄다.
- GitHub 저장소 이름을 `onebite-link`에서 `typography-bookmarks`로 변경했다.
- `onebite-linl`로 잘못 설정되어 있던 로컬 Git의 `origin` 주소를 새 GitHub 저장소 주소로 바로잡았다.
- 로컬 최상위 폴더 이름을 `3.onebite-link`에서 `typography-bookmarks`로 변경했다.
- Supabase 프로젝트와 데이터베이스 설정은 폴더 및 저장소 이름과 독립적이므로 변경하지 않았다.
