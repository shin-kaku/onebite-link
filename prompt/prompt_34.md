# 회원가입 정보 및 사이드바 문구 변경

- 회원가입 화면의 비밀번호 확인 입력란 아래에 비밀번호 조건 안내를 추가했다.
- 비밀번호는 6자 이상이어야 하며 특수기호와 공백을 사용할 수 없도록 실제 가입 검증도 적용했다.
- 회원가입 화면 최상단에 필수 `이름` 입력란을 추가했다.
- 입력한 이름은 Supabase Auth 사용자 메타데이터의 `display_name` 값으로 저장한다.
- 저장된 `display_name`은 로그인 후 사이드바의 사용자 인사말에 표시된다.
- 이름 입력값의 앞뒤 공백을 제거하고 최대 50자까지 입력할 수 있도록 제한했다.
- 사이드바 TIP 문구를 `폴더로 북마크를 정리하면, 나중에 더 쉽게 찾을 수 있어요.`로 변경했다.
